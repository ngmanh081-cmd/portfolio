Heroes World — 2D Action RPG Prototype

A complete 2D action RPG prototype built from scratch with Unity and C#. Covers the full game loop — physics movement, mouse-aimed projectile combat, inventory, quest system, and server-side save/load via JSON and REST API.

Unity 2D C# Gameplay Systems REST API / JSON Singleton Pattern TextMeshPro UI
  • Physics-based player movement using Rigidbody2D and Unity Input System
  • Combat system with mana cost, attack cooldown, and mouse-aimed fireball projectile
  • Inventory & Equipment: stackable items, dynamic slot prefabs, drop/pickup in scene
  • Quest system: accept missions, track kill progress, reward EXP and items on completion
  • Player stats: level, EXP scaling, ATK/HP/MP/Armor with RPG growth formulas
  • Auth & save/load: login, register, persist player data to server via UnityWebRequest
  • Modular Manager architecture: GameManager, InventoryManager, QuestManager, AuthManager
